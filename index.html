开始使用

  1. 将 iPhone 或 iPad 连接到获准访问的设备网络，并允许局域网访问。
  2. 通过“发现设备”寻找开放端口，或手动填写设备地址、端口和协议。开放端口仅提供协议线索。
  3. 连接后运行诊断、浏览支持的地址空间或添加点位查看数据。

没有设备时，可在首页点击“试用示例设备”。演示数据在独立内存环境中生成，不连接真实设备。

无法连接怎么办？

先确认网络可达、地址和端口正确、设备允许相应协议。在 iOS 设置中检查SeqScope的“本地网络”权限；拒绝后可以在设置中重新开启。OPC UA 当前不支持用户名或加密端点，不要为连接工具而降低生产安全设置。

导出与数据管理

报告以 Markdown 导出，监视数据和报文可通过 App 提供的导出操作交给系统分享。选择“存储到文件”后可在“文件”App 中查看。取消分享不会删除报告。可在 App 中删除设备、收藏点位和诊断报告。

协议兼容与能力范围

所有协议均提供只读访问，具体能力取决于设备配置和授权。

Modbus TCP：读取线圈、离散输入及寄存器，批量轮询。不包含串口 Modbus RTU。
Siemens S7：ISO-on-TCP / S7comm，只读地址访问；须与 PLC 的访问权限和数据块设置兼容。
OPC UA：opc.tcp，匿名身份、SecurityPolicy None，地址空间浏览及周期读取。暂不支持用户名身份、签名或加密端点；请勿为连接本工具降低生产设备的安全策略。
MQTT：3.1.1 / 5.0、TLS、订阅与主题查看。主题可见性取决于收到的消息及访问权限。
Open Protocol：拧紧结果订阅、历史补采及报警。支持范围取决于控制器修订版本。

扫描使用 TCP 连接检查；开放端口仅是协议线索。实时查看在前台进行，不提供持续后台采集。PCAP 根据应用报文合成网络头，不用于判断真实 TCP 重传、丢包或整个网络的流量。报告为 Markdown。

Getting started

  1. Join an authorized equipment network and allow Local Network access.
  2. Discover endpoints or enter the device address, port and protocol manually. Open ports are clues, not proof of a protocol.
  3. Connect, run diagnostics and browse or read supported points.

Without equipment, tap “Try a sample device” on the home screen. The demo generates data in an isolated memory environment and makes no equipment connections.

Connection and export help

Check network reachability, device settings, address and port. If you denied Local Network access, enable it for SeqScope in iOS Settings. Do not weaken production security settings to connect. Reports use Markdown. Use the system share sheet to save exports to Files; cancellation leaves the report available. Saved devices, points and reports can be deleted inside the app.

Compatibility and limits

All protocols provide read-only access. Device configuration and permissions determine compatibility.

Modbus TCP: coils, discrete inputs and registers; batch polling. Serial Modbus RTU is not included.
Siemens S7: ISO-on-TCP / S7comm address reads, subject to PLC access and data block configuration.
OPC UA: opc.tcp, anonymous identity and SecurityPolicy None; browsing and periodic reads. Username identity, signed and encrypted endpoints are not supported. Do not weaken production security policies to connect this tool.
MQTT: 3.1.1 / 5.0, TLS, subscriptions and topic viewing. Visible topics depend on received messages and permissions.
Open Protocol: tightening results, historical backfill and alarms; compatibility depends on controller revision.

Discovery checks TCP connections; open ports are protocol clues only. Monitoring runs in the foreground, without continuous background acquisition. PCAP uses synthesized network headers around application messages and cannot establish real TCP loss, retransmission or network-wide traffic. Reports use Markdown.
